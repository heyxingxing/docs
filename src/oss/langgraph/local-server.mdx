本指南介绍如何在本地运行 LangGraph 应用。

## 前置条件

开始之前，请确保你已经拥有：

* 一个 [LangSmith](https://smith.langchain.com/settings) API Key（可免费注册）

## 1. 安装 LangGraph CLI

:::python
<CodeGroup>
```bash pip
# Python >= 3.11 is required.
pip install -U "langgraph-cli[inmem]"
```

```bash uv
# Python >= 3.11 is required.
uv add "langgraph-cli[inmem]"
```
</CodeGroup>
:::

:::js
```shell
npm install --save-dev @langchain/langgraph-cli
```
:::

## 2. 创建 LangGraph 应用

:::python
使用 [`new-langgraph-project-python` 模板](https://github.com/langchain-ai/new-langgraph-project)创建一个新应用。该模板展示了一个单节点应用，你可以在此基础上扩展自己的逻辑。

```shell
langgraph new path/to/your/app --template new-langgraph-project-python
```

<Tip>
**其他模板**

如果执行 `langgraph new` 时不指定模板，会出现一个交互式菜单，让你从可用模板列表中选择。
</Tip>
:::

:::js
使用 [`new-langgraph-project-js` 模板](https://github.com/langchain-ai/new-langgraphjs-project)创建一个新应用。该模板展示了一个单节点应用，你可以在此基础上扩展自己的逻辑。

```shell
npm create langgraph
```

<Accordion title="将 LangGraph 添加到现有项目">
如果你已有一个包含 LangGraph 智能体的项目，可以使用 `config` 命令自动生成 `langgraph.json` 配置文件：

```shell
npm create langgraph config
```

该命令会扫描项目中的 LangGraph 智能体（例如 `createAgent()`、`StateGraph.compile()` 或 `workflow.compile()` 模式），并生成包含所有已导出智能体的配置文件。

示例输出：

```json
{
  "node_version": "24",
  "graphs": {
    "agent": "./src/agent.ts:agent",
    "searchAgent": "./src/search.ts:searchAgent"
  },
  "env": ".env"
}
```

<Tip>
配置文件中只会包含**已导出（exported）**的智能体。如果某个智能体没有导出，命令会给出警告，以便你添加 `export` 关键字。
</Tip>
</Accordion>
:::

## 3. 安装依赖

在新 LangGraph 应用的根目录中安装依赖。Python 项目使用 `edit` 模式，以确保服务器能够使用你的本地代码修改：

:::python
<CodeGroup>
```bash pip
cd path/to/your/app
pip install -e .
```

```bash uv
cd path/to/your/app
uv sync
```
</CodeGroup>
:::

:::js
```shell
cd path/to/your/app
npm install
```
:::

## 4. 创建 `.env` 文件

新 LangGraph 应用根目录中会包含 `.env.example`。在根目录创建 `.env` 文件，将 `.env.example` 的内容复制进去，并填写所需的 API Key：

```bash
LANGSMITH_API_KEY=lsv2...
```

## 5. 启动 Agent Server

在本地启动 LangGraph API Server：

:::python
```shell
langgraph dev
```
:::

:::js
```shell
npx @langchain/langgraph-cli dev
```
:::

示例输出：

```
INFO:langgraph_api.cli:

        Welcome to

╦  ┌─┐┌┐┌┌─┐╔═╗┬─┐┌─┐┌─┐┬ ┬
║  ├─┤││││ ┬║ ╦├┬┘├─┤├─┘├─┤
╩═╝┴ ┴┘└┘└─┘╚═╝┴└─┴ ┴┴  ┴ ┴

- 🚀 API: http://127.0.0.1:2024
- 🎨 Studio UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
- 📚 API Docs: http://127.0.0.1:2024/docs

This in-memory server is designed for development and testing.
For production use, please use LangSmith Deployment.
```

`langgraph dev` 命令会以 In-memory 模式启动 Agent Server。该模式适合开发和测试。生产环境应部署能够访问持久化存储后端的 Agent Server。更多信息请参阅[平台配置概览](/langsmith/platform-setup)。

## 6. 在 Studio 中测试应用

[Studio](/langsmith/studio) 是一个专用 UI，可以连接 LangGraph API Server，在本地可视化、交互和调试应用。运行 `langgraph dev` 后，访问命令输出中的 URL，即可在 Studio 中测试你的图：

```
>    - LangGraph Studio Web UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
```

如果 Agent Server 运行在自定义 Host/Port 上，请修改 URL 中的 `baseUrl` 查询参数。例如，服务器运行在 `http://myhost:3000` 时：

```
https://smith.langchain.com/studio/?baseUrl=http://myhost:3000
```

<Accordion title="Safari 兼容性">
    Safari 连接 localhost Server 时存在一些限制，因此可以在命令中使用 `--tunnel` 参数创建安全隧道：

    ```shell
    langgraph dev --tunnel
    ```
</Accordion>

## 7. 测试 API

:::python
<Tabs>
    <Tab title="Python SDK（异步）">
    1. 安装 LangGraph Python SDK：
        ```shell
        pip install langgraph-sdk
        ```
    2. 向 Assistant 发送消息（无 Thread 的 Run）：
        ```python
        from langgraph_sdk import get_client
        import asyncio

        client = get_client(url="http://localhost:2024")

        async def main():
            async for chunk in client.runs.stream(
                None,  # Threadless run
                "agent", # Name of assistant. Defined in langgraph.json.
                input={
                "messages": [{
                    "role": "human",
                    "content": "What is LangGraph?",
                    }],
                },
            ):
                print(f"Receiving new event of type: {chunk.event}...")
                print(chunk.data)
                print("\n\n")

        asyncio.run(main())
        ```
    </Tab>
    <Tab title="Python SDK（同步）">
    1. 安装 LangGraph Python SDK：
        ```shell
        pip install langgraph-sdk
        ```
    2. 向 Assistant 发送消息（无 Thread 的 Run）：
        ```python
        from langgraph_sdk import get_sync_client

        client = get_sync_client(url="http://localhost:2024")

        for chunk in client.runs.stream(
            None,  # Threadless run
            "agent", # Name of assistant. Defined in langgraph.json.
            input={
                "messages": [{
                    "role": "human",
                    "content": "What is LangGraph?",
                }],
            },
            stream_mode="messages-tuple",
        ):
            print(f"Receiving new event of type: {chunk.event}...")
            print(chunk.data)
            print("\n\n")
        ```
    </Tab>
    <Tab title="REST API">
    ```bash
    curl -s --request POST \
        --url "http://localhost:2024/runs/stream" \
        --header 'Content-Type: application/json' \
        --data "{
            \"assistant_id\": \"agent\",
            \"input\": {
                \"messages\": [
                    {
                        \"role\": \"human\",
                        \"content\": \"What is LangGraph?\"
                    }
                ]
            },
            \"stream_mode\": \"messages-tuple\"
        }"
    ```
    </Tab>
</Tabs>
:::

:::js
<Tabs>
    <Tab title="JavaScript SDK">
    1. 安装 LangGraph JS SDK：
        ```shell
        npm install @langchain/langgraph-sdk
        ```
    2. 向 Assistant 发送消息（无 Thread 的 Run）：
      ```js
      import { Client } from "@langchain/langgraph-sdk";

      // only set the apiUrl if you changed the default port when calling langgraph dev
      const client = new Client({ apiUrl: "http://localhost:2024"});

      const streamResponse = client.runs.stream(
        null, // Threadless run
        "agent", // Assistant ID
        {
          input: {
            "messages": [
              { "role": "user", "content": "What is LangGraph?"}
            ]
          },
          streamMode: "messages-tuple",
        }
      );

      for await (const chunk of streamResponse) {
        console.log(`Receiving new event of type: ${chunk.event}...`);
        console.log(JSON.stringify(chunk.data));
        console.log("\n\n");
      }
      ```
    </Tab>
    <Tab title="REST API">
    ```bash
    curl -s --request POST \
        --url "http://localhost:2024/runs/stream" \
        --header 'Content-Type: application/json' \
        --data "{
            \"assistant_id\": \"agent\",
            \"input\": {
                \"messages\": [
                    {
                        \"role\": \"human\",
                        \"content\": \"What is LangGraph?\"
                    }
                ]
            },
            \"stream_mode\": \"messages-tuple\"
        }"
    ```
    </Tab>
</Tabs>
:::
