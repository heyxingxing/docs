### 连接到你的智能体

Agent Chat UI 既可以连接[本地智能体](/oss/langgraph/studio#set-up-local-agent-server)，也可以连接[已部署的智能体](/oss/langgraph/deploy)。

启动 Agent Chat UI 后，需要配置以下信息来连接你的智能体：

1. **Graph ID**：输入你的图名称（可在 `langgraph.json` 文件的 `graphs` 字段下找到）
2. **Deployment URL**：Agent Server 的服务端点（例如本地开发使用 `http://localhost:2024`，或者填写已部署智能体的 URL）
3. **LangSmith API key（可选）**：填写你的 LangSmith API Key（如果使用本地 Agent Server，则不需要）

配置完成后，Agent Chat UI 会自动获取并显示来自智能体的所有已中断线程。

<Tip>
  Agent Chat UI 原生支持渲染工具调用和工具结果消息。如需自定义显示哪些消息，请参阅 [Hiding Messages in the Chat](https://github.com/langchain-ai/agent-chat-ui?tab=readme-ov-file#hiding-messages-in-the-chat)。
</Tip>
