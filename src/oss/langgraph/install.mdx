title: 安装 LangGraph
sidebarTitle: 安装
---

要安装基础 LangGraph 包：

:::python
<CodeGroup>
```bash pip
pip install -U langgraph
```

```bash uv
uv add langgraph
```
</CodeGroup>
:::

:::js
<CodeGroup>
```bash npm
npm install @langchain/langgraph @langchain/core
```

```bash pnpm
pnpm add @langchain/langgraph @langchain/core
```

```bash yarn
yarn add @langchain/langgraph @langchain/core
```

```bash bun
bun add @langchain/langgraph @langchain/core
```
</CodeGroup>
:::

使用 LangGraph 时，你通常还需要访问 LLM 并定义工具（Tools）。具体采用哪种方式由你决定。

一种常见做法，也是本文档采用的方式，是使用 [LangChain](/oss/langchain/overview)。

安装 LangChain：

:::python
<CodeGroup>
```bash pip
pip install -U langchain
# Requires Python 3.10+
```

```bash uv
uv add langchain
# Requires Python 3.10+
```
</CodeGroup>
:::

:::js
<CodeGroup>
```bash npm
npm install langchain
```

```bash pnpm
pnpm add langchain
```

```bash yarn
yarn add langchain
```

```bash bun
bun add langchain
```
</CodeGroup>
:::

如果要使用特定的 LLM Provider 包，需要单独安装对应依赖。

有关各 Provider 的安装方式，请参阅[集成](/oss/integrations/providers/overview)页面。
