## LangSmith Cloud

本节将介绍如何从 GitHub 仓库将智能体部署到 LangSmith Cloud。基础设施、扩缩容以及运维相关工作均由 LangSmith 负责。

### 前置条件

开始之前，请确保你已经拥有：

- 一个 [GitHub 账号](https://github.com/)
- 一个 [LangSmith 账号](https://smith.langchain.com)（可免费注册）

### 部署你的智能体

#### 1. 在 GitHub 上创建仓库

要部署到 LangSmith，你的应用代码必须位于 GitHub 仓库中，公开仓库和私有仓库均受支持。在本快速入门中，请先按照[本地服务器配置指南](/oss/langgraph/studio#set-up-local-agent-server)确保应用兼容 LangGraph，然后将代码推送到仓库。

#### 2. 部署到 LangSmith

<Steps>
<Step title="进入 LangSmith Deployment">
    登录 [LangSmith](https://smith.langchain.com)。在左侧边栏中选择 **Deployments**。
</Step>
<Step title="创建新部署">
    点击 **+ New Deployment** 按钮。随后会打开一个面板，你可以在其中填写必需字段。
</Step>
<Step title="连接仓库">
    如果你是首次使用，或者要添加此前尚未连接的私有仓库，请点击 **Add new account** 按钮，并按照说明连接你的 GitHub 账号。
</Step>
<Step title="部署仓库">
    选择你的应用仓库，然后点击 **Submit** 开始部署。部署可能需要约 15 分钟。你可以在 **Deployment details** 页面查看状态。
</Step>
</Steps>

#### 3. 在 Studio 中测试应用

应用部署完成后：

1. 选择刚创建的 Deployment，查看详细信息。
2. 点击右上角的 **Studio** 按钮。Studio 会打开并显示你的图。

#### 4. 获取 Deployment 的 API URL

1. 在 LangGraph 的 **Deployment details** 页面中，点击 **API URL** 将其复制到剪贴板。
2. 点击 `URL` 将其复制到剪贴板。

#### 5. 测试 API

现在可以测试 API：

<Tabs>
:::python
<Tab title="Python">
1. 安装 LangGraph SDK：
```shell
pip install langgraph-sdk
```
2. 向智能体发送消息：
```python
from langgraph_sdk import get_sync_client # or get_client for async

client = get_sync_client(url="your-deployment-url", api_key="your-langsmith-api-key")

for chunk in client.runs.stream(
    None,    # Threadless run
    "agent", # Name of agent. Defined in langgraph.json.
    input={
        "messages": [{
            "role": "human",
            "content": "What is LangGraph?",
        }],
    },
    stream_mode="updates",
):
    print(f"Receiving new event of type: {chunk.event}...")
    print(chunk.data)
    print("\n\n")
```
</Tab>
:::
:::js
<Tab title="TypeScript">
1. 安装 LangGraph SDK：
```shell
npm install @langchain/langgraph-sdk
```
2. 向智能体发送消息：
```ts
import { Client } from "@langchain/langgraph-sdk";

const client = new Client({ apiUrl: "your-deployment-url", apiKey: "your-langsmith-api-key" });

const streamResponse = client.runs.stream(
  null,    // Threadless run
  "agent", // Name of agent. Defined in langgraph.json.
  {
    input: {
      "messages": [
        { "role": "user", "content": "What is LangGraph?"}
      ]
    },
    streamMode: "messages",
  }
);

for await (const chunk of streamResponse) {
  console.log(`Receiving new event of type: ${chunk.event}...`);
  console.log(JSON.stringify(chunk.data));
  console.log("\n\n");
}
```
</Tab>
