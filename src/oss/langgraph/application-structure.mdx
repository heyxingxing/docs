一个 LangGraph 应用由一个或多个图、一个配置文件（`langgraph.json`）、一个用于声明依赖的文件，以及一个可选的、用于声明环境变量的 `.env` 文件组成。

本指南展示了典型的应用目录结构，并说明如何提供使用 [LangSmith Deployment](/langsmith/deployment) 部署应用所需的配置。

<Info>
LangSmith Deployment 是一个用于部署和扩展 LangGraph 智能体的托管平台。它会处理基础设施、扩缩容以及运维相关工作，使你能够直接从代码仓库部署有状态、长时间运行的智能体。更多信息请参阅[部署文档](/langsmith/deployment)。
</Info>

## 核心概念

要使用 LangSmith 部署，需要提供以下信息：

1. 一个 [LangGraph 配置文件](#configuration-file-concepts)（`langgraph.json`），用于指定应用所使用的依赖、图和环境变量。
2. 实现应用逻辑的[图](#graphs)。
3. 一个用于声明运行应用所需[依赖](#dependencies)的文件。
4. 应用运行所需的[环境变量](#environment-variables)。

## 文件结构

下面是几种应用目录结构示例：

:::python
<Tabs>
    <Tab title="Python (requirements.txt)">
    ```plaintext
    my-app/
    ├── my_agent # all project code lies within here
    │   ├── utils # utilities for your graph
    │   │   ├── __init__.py
    │   │   ├── tools.py # tools for your graph
    │   │   ├── nodes.py # node functions for your graph
    │   │   └── state.py # state definition of your graph
    │   ├── __init__.py
    │   └── agent.py # code for constructing your graph
    ├── .env # environment variables
    ├── requirements.txt # package dependencies
    └── langgraph.json # configuration file for LangGraph
    ```
    </Tab>
    <Tab title="Python (pyproject.toml)">
    ```plaintext
    my-app/
    ├── my_agent # all project code lies within here
    │   ├── utils # utilities for your graph
    │   │   ├── __init__.py
    │   │   ├── tools.py # tools for your graph
    │   │   ├── nodes.py # node functions for your graph
    │   │   └── state.py # state definition of your graph
    │   ├── __init__.py
    │   └── agent.py # code for constructing your graph
    ├── .env # environment variables
    ├── langgraph.json  # configuration file for LangGraph
    └── pyproject.toml # dependencies for your project
    ```
    </Tab>
</Tabs>
:::

:::js
```plaintext
my-app/
├── src # all project code lies within here
│   ├── utils # optional utilities for your graph
│   │   ├── tools.ts # tools for your graph
│   │   ├── nodes.ts # node functions for your graph
│   │   └── state.ts # state definition of your graph
│   └── agent.ts # code for constructing your graph
├── package.json # package dependencies
├── .env # environment variables
└── langgraph.json # configuration file for LangGraph
```
:::

<Note>
LangGraph 应用的目录结构会根据所使用的编程语言和包管理器而有所不同。
</Note>

## 配置文件

`langgraph.json` 是一个 JSON 文件，用于声明部署 LangGraph 应用所需的依赖、图、环境变量以及其他设置。

有关该 JSON 文件支持的全部字段，请参阅 [LangGraph 配置文件参考](/langsmith/cli#configuration-file)。

<Tip>
[LangGraph CLI](/langsmith/cli) 默认使用当前目录中的 `langgraph.json` 作为配置文件。
</Tip>

### 示例

:::python
* 依赖包括一个本地自定义包和 `langchain_openai` 包。
* 从 `./your_package/your_file.py` 文件中加载一个图，并使用其中的 `agent` 变量。
* 环境变量从 `.env` 文件中加载。

```json
{
  "dependencies": ["langchain_openai", "./your_package"],
  "graphs": {
    "my_agent": "./your_package/your_file.py:agent"
  },
  "env": "./.env"
}
```
:::

:::js
* 依赖会从本地目录中的依赖文件（例如 `package.json`）加载。
* 从 `./your_package/your_file.js` 文件中加载一个图，并使用其中的 `agent` 函数。
* 环境变量 `OPENAI_API_KEY` 直接在配置中设置。

```json
{
  "dependencies": ["."],
  "graphs": {
    "my_agent": "./your_package/your_file.js:agent"
  },
  "env": {
    "OPENAI_API_KEY": "secret-key"
  }
}
```
:::

## 依赖

:::python
LangGraph 应用可能依赖其他 Python 包。
:::

:::js
LangGraph 应用可能依赖其他 TypeScript/JavaScript 库。
:::

通常，你需要提供以下信息，才能正确配置依赖：

:::python
1. 目录中用于声明依赖的文件（例如 `requirements.txt`、`pyproject.toml` 或 `package.json`）。
:::

:::js
1. 目录中用于声明依赖的文件（例如 `package.json`）。
:::

1. 在 [LangGraph 配置文件](#configuration-file-concepts)中通过 `dependencies` 字段声明运行 LangGraph 应用所需的依赖。
2. 其他二进制程序或系统库可以通过 [LangGraph 配置文件](#configuration-file-concepts)中的 `dockerfile_lines` 字段声明。

## 图

在 [LangGraph 配置文件](#configuration-file-concepts)中使用 `graphs` 字段指定部署后的 LangGraph 应用中可用的图。

你可以在配置文件中指定一个或多个图。每个图都由唯一名称和一个路径标识，该路径可以指向：（1）已编译的图，或（2）一个用于创建图的函数。

## 环境变量

如果你在本地使用一个已部署的 LangGraph 应用，可以在 [LangGraph 配置文件](#configuration-file-concepts)的 `env` 字段中配置环境变量。

对于生产部署，通常建议直接在部署环境中配置环境变量。
