title: LangSmith Studio
---

在本地使用 LangChain 构建智能体时，如果能够看到智能体内部发生了什么、实时与它交互，并在问题出现时直接调试，会非常有帮助。**LangSmith Studio** 是一个免费的可视化界面，可用于在本地开发和测试 LangChain 智能体。

Studio 会连接到你本地运行的智能体，并展示智能体执行的每一步：发送给模型的 Prompt、工具调用及其结果，以及最终输出。你可以测试不同输入、检查中间状态，并在不额外编写代码或部署的情况下快速迭代智能体行为。

本页介绍如何为本地 LangChain 智能体配置 Studio。

## 前置条件

开始之前，请确保你已经拥有：

- **LangSmith 账号**：在 [smith.langchain.com](https://smith.langchain.com) 免费注册或登录。
- **LangSmith API Key**：按照[创建 API Key](/langsmith/create-account-api-key)指南完成创建。
- 如果你不希望数据被 [Trace](/langsmith/observability-concepts#traces) 到 LangSmith，请在应用的 `.env` 文件中设置 `LANGSMITH_TRACING=false`。关闭 Tracing 后，数据不会离开本地服务器。

## 配置本地 Agent Server

### 1. 安装 LangGraph CLI

[LangGraph CLI](/langsmith/cli) 提供本地开发服务器（也称为 [Agent Server](/langsmith/agent-server)），用于将你的智能体连接到 Studio。

:::python
```shell
# Python >= 3.11 is required.
pip install --upgrade "langgraph-cli[inmem]"
```
:::

:::js
```shell
npx @langchain/langgraph-cli
```
:::

### 2. 准备智能体

如果你已经有 LangChain 智能体，可以直接使用。下面示例使用一个简单的邮件智能体：

:::python
```python title="agent.py"
from langchain.agents import create_agent

def send_email(to: str, subject: str, body: str):
    """Send an email"""
    email = {
        "to": to,
        "subject": subject,
        "body": body
    }
    # ... email sending logic

    return f"Email sent to {to}"

agent = create_agent(
    "gpt-5.5",
    tools=[send_email],
    system_prompt="You are an email assistant. Always use the send_email tool.",
)
```
:::

:::js
```typescript title="agent.ts"
import { createAgent } from "@langchain/langgraph";

function sendEmail(to: string, subject: string, body: string): string {
    // Send an email
    const email = {
        to: to,
        subject: subject,
        body: body
    };
    // ... email sending logic

    return `Email sent to ${to}`;
}

const agent = createAgent({
    model: "gpt-5.5",
    tools: [sendEmail],
    systemPrompt: "You are an email assistant. Always use the sendEmail tool.",
});

export { agent };
```
:::

### 3. 环境变量

Studio 需要 LangSmith API Key 才能连接到你的本地智能体。在项目根目录创建 `.env` 文件，并添加从 [LangSmith](https://smith.langchain.com/settings) 获取的 API Key。

<Warning>
    请确保 `.env` 文件不会被提交到 Git 等版本控制系统中。
</Warning>

```bash .env
LANGSMITH_API_KEY=lsv2...
```

### 4. 创建 LangGraph 配置文件

LangGraph CLI 使用配置文件来定位你的智能体并管理依赖。在应用目录中创建 `langgraph.json`：

:::python
```json title="langgraph.json"
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./src/agent.py:agent"
  },
  "env": ".env"
}
```
:::

:::js
```json title="langgraph.json"
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./src/agent.ts:agent"
  },
  "env": ".env"
}
```
:::

:::python
@[`create_agent`] 函数会自动返回一个已经编译的 LangGraph 图，这正是配置文件中 `graphs` 字段所需要的对象。
:::

:::js
@[`createAgent`] 函数会自动返回一个已经编译的 LangGraph 图，这正是配置文件中 `graphs` 字段所需要的对象。
:::

<Info>
关于配置文件 JSON 对象中各字段的详细解释，请参阅 [LangGraph 配置文件参考](/langsmith/cli#configuration-file)。
</Info>

此时项目结构如下：

:::python
```bash
my-app/
├── src
│   └── agent.py
├── .env
└── langgraph.json
```
:::

:::js
```bash
my-app/
├── src
│   └── agent.ts
├── .env
├── package.json
└── langgraph.json
```
:::

### 5. 安装依赖

:::python
在项目根目录安装依赖：

<CodeGroup>
```shell pip
pip install langchain langchain-openai
```
```shell uv
uv add langchain langchain-openai
```
</CodeGroup>
:::

:::js
```shell
yarn install
```
:::

### 6. 在 Studio 中查看智能体

启动开发服务器，将智能体连接到 Studio：

:::python
```shell
langgraph dev
```
:::

:::js
```shell
npx @langchain/langgraph-cli dev
```
:::

<Warning>
Safari 会阻止 Studio 连接 `localhost`。可以在上述命令后添加 `--tunnel`，通过安全隧道访问 Studio。随后需要在 Studio UI 中点击 **Connect to a local server**，手动把 Tunnel URL 添加到允许的 Origin。具体步骤请参阅[故障排查指南](/langsmith/troubleshooting-studio#safari-connection-issues)。
</Warning>

服务器启动后，可以通过 `http://127.0.0.1:2024` 的 API 访问智能体，也可以通过 `https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024` 在 Studio UI 中访问：

<Frame>
![Studio UI 中的智能体视图](/oss/images/studio_create-agent.png)
</Frame>

Studio 连接本地智能体后，你就可以快速迭代智能体行为。运行测试输入，并在 [LangSmith](/langsmith/observability-studio) 中检查完整执行 Trace，包括 Prompt、工具参数、返回值以及 Token/延迟指标。当出现问题时，Studio 会连同周围状态一起记录异常，帮助你理解具体发生了什么。

开发服务器支持热重载（Hot Reload）：修改代码中的 Prompt 或工具签名后，Studio 会立即反映这些变化。你还可以从对话线程中的任意步骤重新运行，以测试修改效果，而无需从头开始。这套工作流既适用于简单的单工具智能体，也能扩展到复杂的多节点图。
