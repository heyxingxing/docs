LangGraph 已被 Klarna、Uber、J.P. Morgan 等塑造智能体未来的公司采用。它是一个面向长时间运行、有状态智能体的低层编排框架与运行时，可用于构建、管理和部署此类智能体。LangGraph 允许你在同一张图中精细地组合确定性的手写步骤与由 LLM 驱动的智能体步骤，从而构建完全符合应用需求的定制智能体。

LangGraph 的抽象层级很低，并且完全聚焦于智能体**编排（orchestration）**。在使用 LangGraph 之前，我们建议先熟悉一些构建智能体时常用的基础组件，可以从[模型](/oss/langchain/models)和[工具](/oss/langchain/tools)开始。

在本文档中，我们会经常使用 [LangChain](/oss/langchain/overview) 的组件来集成模型和工具，但使用 LangGraph 并不要求必须使用 LangChain。如果你刚开始接触智能体，或者希望使用更高层的抽象，我们建议使用 LangChain 的[智能体](/oss/langchain/agents)。它为常见的 LLM 与工具调用循环提供了预构建架构。

LangGraph 聚焦于智能体编排所需的底层核心能力，包括持久化执行、流式输出、人在回路（human-in-the-loop）等。

LangGraph 的核心优势之一，是能够在一张图中混合确定性步骤与由 LLM 驱动的智能体步骤。这样，你可以构建定制工作流：部分逻辑完全可预测、可审计，另一些部分则保持灵活并由模型驱动，从而精确控制 AI 在哪里、以什么方式参与执行。

<Expandable title="LangChain 各产品之间的关系" defaultOpen={false}>

- [Deep Agents](/oss/deepagents/overview) 是构建在 LangGraph 之上的 [Agent Harness](/oss/concepts/products#agent-harnesses-like-the-deep-agents-sdk)，提供规划、子智能体、文件系统工具和上下文管理等能力。
- [LangChain](/oss/langchain/overview) 是智能体框架，为模型、工具和智能体循环提供抽象与集成。
- [LangGraph](/oss/langgraph/overview) 是编排运行时，提供持久化执行、流式输出、人在回路以及持久化能力。
- [LangSmith](/langsmith/observability) 是跨框架的追踪、评测、Prompt 管理与部署平台。
- [LangSmith Engine](/langsmith/engine) 可以从 LangGraph 智能体的 Trace 中检测问题并提出修复建议，你还可以直接从 Engine 标签页发起包含建议修复的 Pull Request。
- [LangSmith Fleet](/langsmith/fleet/index) 是一个无代码智能体构建器，用于模板、集成与常规自动化。

如需比较这套开源技术栈中的框架、运行时和 Harness，请阅读[框架、运行时与 Harness](/oss/concepts/products)。
</Expandable>

然后，创建一个简单的 Hello World 示例：

:::python
```python
from langgraph.graph import StateGraph, MessagesState, START, END

def mock_llm(state: MessagesState):
    return {"messages": [{"role": "ai", "content": "hello world"}]}

graph = StateGraph(MessagesState)
graph.add_node(mock_llm)
graph.add_edge(START, "mock_llm")
graph.add_edge("mock_llm", END)
graph = graph.compile()

graph.invoke({"messages": [{"role": "user", "content": "hi!"}]})
```
:::

:::js
```typescript
import { StateSchema, MessagesValue, type GraphNode, StateGraph, START, END } from "@langchain/langgraph";

const State = new StateSchema({
  messages: MessagesValue,
});

const mockLlm: GraphNode<typeof State> = (state) => {
  return { messages: [{ role: "ai", content: "hello world" }] };
};

const graph = new StateGraph(State)
  .addNode("mock_llm", mockLlm)
  .addEdge(START, "mock_llm")
  .addEdge("mock_llm", END)
  .compile();

await graph.invoke({ messages: [{ role: "user", content: "hi!" }] });
```
:::

<Tip>
使用 [LangSmith](/langsmith/observability) 追踪请求、调试智能体行为并评估输出。设置 `LANGSMITH_TRACING=true` 和你的 API Key 即可开始使用。按照[Tracing 快速入门](/langsmith/trace-with-langchain)完成配置。我们还建议设置 [LangSmith Engine](/langsmith/engine)，它可以监控 Trace、检测问题并提出修复建议。
</Tip>

## 核心优势

LangGraph 为**任何**长时间运行、有状态的工作流或智能体提供低层基础设施。LangGraph 不会替你抽象 Prompt 或智能体架构，而是提供以下核心能力：

* **混合确定性步骤与智能体步骤**：在同一张图中组合手写的确定性逻辑与由 LLM 驱动的决策。需要可靠性和可预测性时使用确定性步骤，需要灵活性时使用智能体步骤，从而精确控制智能体的每一部分行为。
* [持久化](/oss/langgraph/persistence)：构建能够跨故障持续运行、长时间执行，并从上次停止位置恢复的智能体。
* [人在回路](/oss/langgraph/interrupts)：通过在任意时刻检查和修改智能体状态，引入人工监督。
* [完整的记忆机制](/oss/concepts/memory)：构建有状态智能体，同时拥有支持当前推理的短期工作记忆，以及跨会话保存的长期记忆。
* [使用 LangSmith 调试](/langsmith/observability)：借助可视化工具深入观察复杂智能体行为，包括追踪执行路径、记录状态迁移以及提供详细的运行时指标。
* [生产级部署](/langsmith/deployment)：使用专为有状态、长时间运行工作流设计的可扩展基础设施，更可靠地部署复杂智能体系统。
