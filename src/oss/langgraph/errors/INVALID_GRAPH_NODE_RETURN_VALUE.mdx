---
title: INVALID_GRAPH_NODE_RETURN_VALUE
---

:::python
LangGraph @[`StateGraph`] 收到了某个节点返回的非 `dict` 类型结果。例如：

```python
from typing import TypedDict

from langgraph.graph import StateGraph

class State(TypedDict):
    some_key: str

def bad_node(state: State):
    # Should return a dict with a value for "some_key", not a list
    return ["whoops"]

builder = StateGraph(State)
builder.add_node(bad_node)
...

graph = builder.compile()
```

调用上面的图时，会得到类似下面的错误：

```python
graph.invoke({ "some_key": "someval" });
```

```
InvalidUpdateError: Expected dict, got ['whoops']
For troubleshooting, visit: https://docs.langchain.com/oss/python/langgraph/errors/INVALID_GRAPH_NODE_RETURN_VALUE
```

图中的节点必须返回一个 `dict`，其中包含你在 State 中定义的一个或多个 Key。
:::

:::js
LangGraph @[`StateGraph`] 收到了某个节点返回的非对象类型结果。例如：

```typescript
import { z } from "zod/v4";
import { StateGraph, StateSchema, GraphNode } from "@langchain/langgraph";

const State = new StateSchema({
  someKey: z.string(),
});

const badNode: GraphNode<typeof State> = (state) => {
  // Should return an object with a value for "someKey", not an array
  return ["whoops"];
};

const builder = new StateGraph(State).addNode("badNode", badNode);
// ...

const graph = builder.compile();
```

调用上面的图时，会得到类似下面的错误：

```typescript
await graph.invoke({ someKey: "someval" });
```

```
InvalidUpdateError: Expected object, got ['whoops']
For troubleshooting, visit: https://langchain-ai.github.io/langgraphjs/troubleshooting/errors/INVALID_GRAPH_NODE_RETURN_VALUE
```

图中的节点必须返回一个对象，其中包含你在 State 中定义的一个或多个 Key。
:::

## 故障排查

以下做法通常可以解决这个错误：

:::python
* 如果节点内部包含较复杂的控制逻辑，请检查所有代码路径，确保它们最终都会为已定义的 State 返回合适的 `dict`。
:::

:::js
* 如果节点内部包含较复杂的控制逻辑，请检查所有代码路径，确保它们最终都会为已定义的 State 返回合适的对象。
:::
