---
title: INVALID_CONCURRENT_GRAPH_UPDATE
---

LangGraph @[`StateGraph`] 收到了来自多个节点的并发状态更新，但被更新的 State 字段并不支持这种并发写入。

一种常见情况是：你的图使用了[扇出（fanout）](/oss/langgraph/use-graph-api#map-reduce-and-the-send-api)或其他并行执行方式，同时又定义了类似下面这样的 State：

:::python
```python
from typing import TypedDict

from langgraph.graph import START, StateGraph

class State(TypedDict):
    some_key: str  # [!code highlight]

def node(state: State):
    return {"some_key": "some_string_value"}

def other_node(state: State):
    return {"some_key": "some_string_value"}


builder = StateGraph(State)
builder.add_node(node)
builder.add_node(other_node)
builder.add_edge(START, "node")
builder.add_edge(START, "other_node")
graph = builder.compile()
```
:::

:::js
```typescript
import { StateGraph, StateSchema, START } from "@langchain/langgraph";
import { z } from "zod/v4";  // [!code highlight]

const State = new StateSchema({
  someKey: z.string(),
});

const builder = new StateGraph(State)
  .addNode("node", (state) => {
    return { someKey: "some_string_value" };
  })
  .addNode("otherNode", (state) => {
    return { someKey: "some_string_value" };
  })
  .addEdge(START, "node")
  .addEdge(START, "otherNode");

const graph = builder.compile();
```
:::

:::python
如果上面图中的某一个节点返回 `{ "some_key": "some_string_value" }`，它会把 State 中 `"some_key"` 的值覆盖为 `"some_string_value"`。
但如果同一个 Step 内的多个并行节点（例如 fanout 分支）都返回了 `"some_key"`，LangGraph 就无法确定应该如何合并这些更新，因此会抛出此错误。
:::

:::js
如果上面图中的某一个节点返回 `{ someKey: "some_string_value" }`，它会把 State 中 `someKey` 的值覆盖为 `"some_string_value"`。
但如果同一个 Step 内的多个并行节点（例如 fanout 分支）都返回了 `someKey`，LangGraph 就无法确定应该如何合并这些更新，因此会抛出此错误。
:::

要解决这个问题，可以为该字段定义一个能够合并多个值的 Reducer：

:::python
```python
import operator
from typing import Annotated

class State(TypedDict):
    # The operator.add reducer fn makes this append-only  # [!code highlight]
    some_key: Annotated[list, operator.add]  # [!code highlight]
```
:::

:::js
```typescript
import { StateSchema, ReducedValue } from "@langchain/langgraph";
import { z } from "zod/v4";

const State = new StateSchema({  // [!code highlight]
  someKey: new ReducedValue(  // [!code highlight]
    z.array(z.string()).default(() => []),  // [!code highlight]
    {
      inputSchema: z.array(z.string()),
      reducer: (existing, update) => existing.concat(update),  // [!code highlight]
    }
  ),
});
```
:::

这样就可以显式定义：当多个并行节点返回同一个 State Key 时，应该如何合并它们的结果。

## 故障排查

以下做法通常可以解决这个错误：

* 如果你的图会并行执行多个节点，请确保所有可能被并发更新的 State Key 都定义了合适的 Reducer。
