---
title: GRAPH_RECURSION_LIMIT
---

你的 LangGraph @[`StateGraph`] 在到达停止条件之前，已经执行到了允许的最大步数。
这通常是因为代码中存在无限循环，例如下面这种情况：

:::python
```python
from typing import TypedDict

from langgraph.graph import StateGraph

class State(TypedDict):
    some_key: str

builder = StateGraph(State)
builder.add_node("a", ...)
builder.add_node("b", ...)
builder.add_edge("a", "b")
builder.add_edge("b", "a")
...

graph = builder.compile()
```
:::

:::js
```typescript
import { StateGraph, StateSchema } from "@langchain/langgraph";
import { z } from "zod/v4";

const State = new StateSchema({
  someKey: z.string(),
});

const builder = new StateGraph(State)
  .addNode("a", ...)
  .addNode("b", ...)
  .addEdge("a", "b")
  .addEdge("b", "a")
  ...

const graph = builder.compile();
```
:::

不过，对于本身就很复杂的图，也有可能在正常情况下自然达到默认限制。

## 故障排查

* 如果你并不预期图会执行很多轮，那么很可能存在一个循环。请检查控制逻辑中是否有无限循环。

:::python
* 如果你的图确实比较复杂，可以在调用图时，通过 `config` 对象传入更高的 `recursion_limit`：

```python
graph.invoke({...}, {"recursion_limit": 1000})
```
:::

:::js
* 如果你的图确实比较复杂，可以在调用图时，通过 `config` 对象传入更高的 `recursionLimit`：

```typescript
await graph.invoke({...}, { recursionLimit: 1000 });
```
:::
